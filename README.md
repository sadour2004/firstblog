# Moroccan Tourism Blog

A modern, multilingual blog platform showcasing the beauty and culture of Morocco. Built with Next.js and React, this platform provides an engaging experience for travelers interested in exploring Morocco.

## Features

- 🌐 Full multilingual support (English & French)
- 📱 Responsive design for all devices
- 🎨 Modern UI with smooth animations
- 📝 Blog system with categories and search
- 📧 Contact form with Google Maps integration
- 📧 Newsletter subscription
- 🔍 SEO optimized

## Tech Stack

- Next.js
- React
- Tailwind CSS
- next-i18next for translations

## Getting Started

1. Clone the repository:
```bash
git clone https://github.com/yourusername/moroccan-tourism-blog.git
cd moroccan-tourism-blog
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
