# Moroccan Tourism Blog

A professional, multilingual blog focused on tourism in Morocco, built with Next.js and React.

## Features

- Multilingual support (English, Arabic, French)
- Responsive design with Tailwind CSS
- SEO optimized
- Blog posts about Tangier, Rabat, Marrakech, Casablanca, and Fez

## Getting Started

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd moroccan-tourism-blog
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure

- `/pages`: Next.js pages
- `/components`: React components
- `/public/locales`: Translation files
- `/styles`: Global styles and Tailwind CSS

## Technologies Used

- Next.js
- React
- next-i18next
- Tailwind CSS
